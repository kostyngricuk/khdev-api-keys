# Introducing KHDev API Keys

KHDev API Keys is where you get and manage the license keys for the KHDev solutions you bought.
Every purchase gives you one key. You paste the key into the solution's settings on your site,
and it activates itself.

## Solutions

| Solution       | Platform   |
| -------------- | ---------- |
| Personal Price | 1С-Битрикс |

More solutions for WordPress, OpenCart and Shopify are coming.

## How access works

KHDev API Keys is invitation-only. You cannot sign up yourself. After you buy a plugin, you receive an email
with a link to the dashboard. You sign in with that email address and a one-time code, with no password
to remember. See [Authentication](./authentication.md).

## Your license key

A key looks like this:

```text
A1B2-C3D4-E5F6-0789-0FZL-0G9Q
```

The first four groups are random. The last two groups record the day the key was created and the day it expires.

Each key:

- works for **one solution** (for example Personal Price on 1С-Битрикс)
- is valid for **one year**; after that it expires and you can extend it
- can be activated on **3 domains**; activating it again on a domain that already uses it does not count

## What you can do with a key

| Action     | What happens                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------- |
| Regenerate | You get a new key and all 3 activations are free again. The old key stops working everywhere. |
| Extend     | An expired key is renewed for another year and becomes active.                                  |
| Deactivate | The key stops working until you activate it again.                                              |

Keys cannot be deleted. New keys are created only when you buy a plugin.
