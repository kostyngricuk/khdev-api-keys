# Введение в KHDev API Keys

KHDev API Keys — это место, где вы получаете лицензионные ключи для купленных решений KHDev и управляете ими.
Каждая покупка даёт один ключ. Вы вставляете ключ в настройки решения на своём сайте, и оно активируется.

## Решения

| Решение             | Платформа  |
| ------------------- | ---------- |
| Персональные скидки | 1С-Битрикс |

Скоро появятся решения для WordPress, OpenCart и Shopify.

## Как устроен доступ

KHDev API Keys работает только по приглашениям: зарегистрироваться самостоятельно нельзя. После покупки
вы получите письмо со ссылкой на дашборд. Вход — по этому email и одноразовому коду, без пароля.
Подробнее — в разделе [Авторизация](./authentication.md).

## Ваш лицензионный ключ

Ключ выглядит так:

```text
A1B2-C3D4-E5F6-0789-0FZL-0G9Q
```

Первые четыре группы случайные. Последние две хранят дату создания ключа и дату окончания его действия.

Каждый ключ:

- работает для **одного решения** (например, «Персональные скидки» для 1С-Битрикс)
- действует **один год**; после этого он истекает, и его можно продлить
- активируется на **3 доменах**; повторная активация на домене, где ключ уже используется, не считается

## Что можно сделать с ключом

| Действие       | Что происходит                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------- |
| Перевыпустить  | Вы получаете новый ключ, все 3 активации снова свободны. Старый ключ сразу перестаёт работать везде. |
| Продлить       | Истёкший ключ продлевается ещё на год и снова становится активным.                                  |
| Деактивировать | Ключ перестаёт работать, пока вы снова его не активируете.                                          |

Ключи нельзя удалить. Новые ключи создаются только при покупке решения.
